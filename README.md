## 👋 Sobre mim

Sou apaixonado por tecnologia, principalmente quando ela sai do código e vira impacto real no dia a dia de alguém. Gosto de entender o problema inteiro antes de sair escrevendo linha de código, da modelagem do banco até a última tela que o usuário vê. Estou cursando Ciência da Computação na UnB e Tecnólogo em Banco de Dados no Senac, e ando de olho em como a IA está mudando a forma de programar, tanto pra acelerar o trabalho quanto pra levantar novas perguntas sobre o que realmente vale a pena automatizar. Fora do teclado, curto uma boa sessão de jogos, e música é praticamente item obrigatório enquanto estou desenvolvendo meus projetos/atividades, sempre rolando alguma playlist no fundo.

## 🚀 Contribuições Sob Fogo

> [!WARNING]
> **NENHUM COMMIT SERÁ PERDOADO!!!** A Code Destroyer não conhece limites, piedade ou `git revert`. Ela atravessa o histórico do ano inteiro como uma máquina de destruição, atirando em tudo que encontra pela frente. Branches são executadas, commits são eliminados e o histórico inteiro é condenado ao caos. E quando você pensa que finalmente acabou… ela volta no tempo e começa tudo de novo. Porque para a Code Destroyer, o passado não é história, é apenas um território ainda não destruído. E enquanto existir um commit perdido em algum lugar do histórico, ela continuará sua caçada. **O código pode até sobreviver… mas a Code Destroyer sempre volta.** ☠️🔥
